# Security

## Boundaries

- Mock mode is the default and requires no credentials.
- The knowledge base contains only newly written fictional guidance.
- Long numeric identifiers are rejected before retrieval and tool execution.
- The mock invoice tool accepts only three allowlisted fields and always requires confirmation.
- Unsupported advice is escalated instead of inferred.

Do not put real taxpayer data, credentials, tax material, endpoints, recordings, exports, or organization metadata in this repository.

## Reporting

Report a vulnerability through GitHub private vulnerability reporting. Do not include a working credential or personal data in a public issue.
